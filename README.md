# MOQO Clone

A front-end clone of the MOQO ice-cream brand website, built as a design practice project. It recreates the look of the original site as a single static page.

## Live Demo

https://hormaz-moqo.netlify.app/

## Features

- Single-page recreation of the MOQO site design

## Tech Stack

- Plain HTML, CSS and JavaScript

## Getting Started

No install or build step is needed. Just open the page:

```bash
# open this file in a browser
index.html
```

Or host the folder on any static host (Netlify, Vercel, GitHub Pages, etc.).

## Notes

A practice clone made for learning front-end layout and styling — not affiliated with MOQO.
